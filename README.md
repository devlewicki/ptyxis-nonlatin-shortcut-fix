# Ptyxis non-Latin Shortcut Fix

Форк [Ptyxis](https://gitlab.gnome.org/GNOME/ptyxis) (на базе версии 50.1) с исправлением работы клавиатурных шорткатов при не-латинских раскладках (кириллица и др.).

## Исправления

### Копирование и вставка при не-латинской раскладке

**Проблема.** Шорткаты `Ctrl+Shift+C` и `Ctrl+Shift+V` в терминале не срабатывали, когда активна не-латинская раскладка клавиатуры (например, русская). Сопоставление происходило по символу (keyval), который выдаёт нажатие в текущей раскладке, а не по физической клавише. Для раскладки RU символ, порождаемый клавишей `C`, — это `С` (кириллическая), поэтому сопоставление с латинским `c`/`v` не срабатывало.

**Причина.** Обработчик `ptyxis_terminal_capture_key_pressed_cb()` сравнивал keyval события нажатия со шорткатом напрямую; при этом шорткат, заданный как латинская клавиша, не совпадал с keyval, полученным от не-латинской раскладки.

**Решение.** Сопоставление переведено на физическую клавишу (keycode):
1. Шорткат разбирается в пару «keyval + модификаторы» (`gtk_accelerator_parse`).
2. Проверяются модификаторы события с учётом потреблённых (`gdk_key_event_get_consumed_modifiers`).
3. keyval шортката раскладывается обратно в набор физических клавиш (`gdk_display_map_keyval`), и keycode события нажатия сверяется с этим набором.

Так, шорткат определяется физическим положением клавиши независимо от текущей раскладки, а также от того, какая клавиша указана в конфигурации.

**Покрытие.** Охвачено два действия терминала: `copy-clipboard` и `paste-clipboard`. Сопоставление читает значение шортката из настроек, поэтому уважает пользовательские комбинации, заданные в *Preferences → Keyboard Shortcuts*.

**Затронутые файлы:**
- `src/ptyxis-terminal.c`
  - `ptyxis_terminal_keycode_matches_accel()` — новая функция: сопоставление события нажатия со шорткатом по keycode.
  - `ptyxis_terminal_capture_key_pressed_cb()` — вызов нового механизма для действий `copy-clipboard` и `paste-clipboard`.

## Сборка

```bash
meson setup _build --prefix=/usr/local --buildtype=release
meson compile -C _build
sudo meson install -C _build
```
